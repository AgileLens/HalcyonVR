## 📖 About

Halcyon VR is a community-driven, open-source project dedicated to preserving and recreating the Disney Star Wars: Galactic Starcruiser experience in virtual reality and flatscreen formats. Our mission is to archive this unique experience for fans worldwide.

**Important:** This project is not affiliated with Disney in any way. It is a fan-created documentation and preservation effort using publicly available materials with no commercial intent.

---

## 🌟 Features

- Full VR and flatscreen compatibility
- Faithful recreation of the Galactic Starcruiser experience
- Community-driven development
- Open-source preservation effort
- Cross-platform support (Windows 10/11, Meta Quest)
