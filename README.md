## Things to Try

1. **Download and run the PCVR build:** Grab the [latest release (v0.0.5)](https://github.com/AgileLens/HalcyonVR/releases/tag/v.0.0.5) and launch it with your headset connected via Quest Link or Air Link — the Galactic Starcruiser experience runs in PCVR without any UE5 setup needed.
2. **Install via App Lab:** Use the [App Lab link](https://www.meta.com/s/7sFjKg3nF) to sideload directly onto your Quest headset for standalone wireless play.
3. **Join the community Discord:** Drop into the [Discord server](https://discord.gg/SKwFxcERA8) — it's the hub for archival contribution coordination, bug reports, and historical reference gathering. Introduce yourself and mention any Halcyon reference materials you might have.
4. **Browse the Halcyon Compendium:** Visit the [Notion compendium](https://halcyonarchive.notion.site/Halcyon-Compendium-df8ffe179a584ba099c763bc14be7e12) to see the crowd-sourced photo archive of the ship's spaces, props, and signage that guides the UE5 reconstruction.
5. **Contribute reference materials:** If you visited the Star Wars Galactic Starcruiser before it closed in 2023, share your photos on Discord or via a GitHub issue — this is an open-source community preservation project and every new reference image helps improve accuracy.

Halcyon VR is a fan, community, and open-source project that aims to remake and preserve as much as possible (that is allowed) of the Disney Star Wars Galactic Starcruiser experience in VR and flatscreen.  It is not associated with Disney in any way. This is a documentation effort using publicly available assets and no commercial outcome.
